# TestGame

A Roblox experience built in Roblox Studio.

## Requirements

- [Roblox Studio](https://create.roblox.com/)
- [Claude Code](https://claude.com/claude-code) (optional, for AI-assisted development)

## Getting started

1. Open the TestGame place in Roblox Studio.
2. Press **Play** (F5) to test locally.

## Working with Claude Code

This folder includes an [.mcp.json](.mcp.json) that connects Claude Code to Roblox Studio through
Roblox's built-in Studio MCP server. With Studio open:

1. Open this folder in Claude Code.
2. Approve the `Roblox_Studio` MCP server when prompted.
3. Claude can now read and edit the place directly in Studio.

See [CLAUDE.md](CLAUDE.md) for project conventions.
